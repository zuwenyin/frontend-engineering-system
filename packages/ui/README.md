# @zuwy/frontend-engineering-system-ui

Shared React UI components for frontend-engineering-system2.

## Install

```bash
pnpm add @zuwy/frontend-engineering-system-ui react react-dom
```

## Usage

```tsx
import { Button } from "@zuwy/frontend-engineering-system-ui"
import "@zuwy/frontend-engineering-system-ui/styles.css"

export function Example() {
  return <Button>Save</Button>
}
```
